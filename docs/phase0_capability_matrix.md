## Coverage of the Seed Catalogue

- **Satellite parking-lot car counts**: best status REACHABLE_DATA. Weak: Sentinel-2 (10 m) and Landsat (30 m) cannot resolve cars. The only free sub-metre imagery is NAIP (US, ~biennial), listed in Earth Search / Planetary Computer ('naip' collection, item-level download untested: https://planetarycomputer.microsoft.com/api/stac/v1/collections/naip). A weekly car-count signal needs commercial imagery; treat as not sourceable free.
- **Night-time light intensity (NASA VIIRS) and thermal imagery of plants, smelters, refineries**: best status REACHABLE_DATA. Quantitative radiance needs a free Earthdata login (Black Marble, FIRMS thermal anomalies); GIBS only gives rendered tiles. EOG nightly mosaics fail because the container trust store lacks the emSign root CA - ask the environment owner to add it. CMR granule search for VNP46A2 (same cmr.earthdata.nasa.gov host that worked for SMAP) is the keyless discovery path.
- **Flaring and emissions from Sentinel-5P (methane, NO2)**: best status REACHABLE_DATA. Adequate: catalogue search keyless, downloads with a free CDSE token, Carbon Mapper plumes keyless. Keyless S5P L2 files also sit on the AWS Open Data 'meeo-s5p' bucket (https://meeo-s5p.s3.amazonaws.com/ - untested).
- **AIS ship tracking: vessel queues at single-company ports, LNG terminals, mining export docks**: best status REACHABLE_DATA. Only US-waters historical AIS (months of lag) is free; no live/global queue feed was reached. Not probed: aisstream.io (free API key, websocket wss://stream.aisstream.io/v0/stream) and Kystverket (Norway) open AIS; retry web.ais.dk for the Danish archive. Non-US LNG/mining ports therefore remain uncovered.
- **Public seismometer networks picking up quarry and mine blasting frequency**: best status REACHABLE_DATA. Fully covered: USGS catalog filters by eventtype with a /count endpoint; raw waveforms via EarthScope dataselect.
- **Truck counts from state DOT traffic counters near large distribution centers; weekly rail carloads by commodity**: best status REACHABLE_DATA. Trucks: FHWA TMAS monthly continuous-count zips (hourly volume + vehicle class, months of lag) and state ArcGIS feeds work; Drakewell needs a browser. Rail: BNSF PDFs + STB-1251 service CSV work; AAR commodity detail is paid. AAR's free weekly 'Rail Traffic' press release (https://www.aar.org/news/, curl UA) and CSX/NS weekly carload PDFs were not probed.
- **Municipal water and power usage for large industrial users, and permit renewals**: best status REACHABLE_DATA. Weak for usage: no customer-level industrial consumption dataset was found. ECHO covers NPDES/air permit status and expiry (permit renewals). Untested: ECHO DMR bulk downloads (monthly per-facility discharge flow, https://echo.epa.gov/tools/data-downloads) and EIA-923 monthly plant fuel use as production proxies.
- **River levels (Rhine, Mississippi) and soil moisture**: best status REACHABLE_DATA. Fully covered; soil moisture needs a free Earthdata login (SMAP). Pegelonline limits history per request (~31 days), so page by window.
- **Wastewater epidemiology as a demand lead for pharma and consumer-health**: best status REACHABLE_DATA. Covered for SARS-CoV-2; the same Socrata host carries NWSS flu A / RSV datasets (not probed). WastewaterSCAN has no documented API - download via UI or inspect its Nuxt JSON calls.
- **Local planning-committee minutes and permit applications for data centers, plants, warehouses**: best status REACHABLE_DATA. Covered only for Legistar and CivicPlus jurisdictions; no national aggregator exists. Structured building-permit feeds on Socrata portals (e.g. Chicago https://data.cityofchicago.org/resource/ydr8-5enu.json) were not probed, but Socrata hosts worked elsewhere.
- **Utility interconnection and power-capacity requests**: best status REACHABLE_DATA. CAISO and ERCOT reachable, PJM via free key; MISO and LBNL blocked by Cloudflare. Not probed and keyless: SPP active queue CSV (https://opsportal.spp.org/Studies/GenerateActiveCSV), NYISO interconnection queue xlsx, ISO-NE IRTT - would cover most ISOs without a browser.
- **WARN Act mass-layoff notices**: best status REACHABLE_DATA. Good multi-state coverage; Texas needs a real browser. Open-source multi-state scrapers (PyPI 'warn-scraper' by Big Local News) were not tested.

- crt.sh certificate search is marked ERROR, but its evidence is a successful 1,055,776-byte JSON with 3,320 rows; it should be REACHABLE_DATA.
